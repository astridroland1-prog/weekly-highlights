# Weekly Highlights – Marketing Feldschlösschen

Formulaire bilingue (DE/FR) avec lequel chaque membre de l'équipe marketing prépare sa contribution hebdomadaire.

- **Lien pour l'équipe :** https://astridroland1-prog.github.io/weekly-highlights/
- **Fonctionnement :** chacun remplit les trois rubriques (Highlights der Woche, Ausblick nächste Woche, Team), copie le texte généré et l'envoie par e-mail ou Teams. Le brouillon reste uniquement dans le navigateur de la personne ; rien n'est stocké en ligne.
- **Format du texte :** titres toujours en allemand et ligne de fin `-- Ende Weekly Highlights --`, pour pouvoir compiler les contributions automatiquement.

## Modifier le formulaire
Tout se trouve dans `index.html`. L'adresse de réception se règle en haut du script (`RECIPIENT`).
Chaque modification publiée sur la branche `main` met le lien à jour en une à deux minutes.
